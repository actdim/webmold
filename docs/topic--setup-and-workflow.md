# WebMold Setup and Workflow

## Installation

```bash
pnpm install
```

## Development Commands

```bash
# Run webapp only (port 5174)
pnpm dev:webapp

# Run Fastify server only (port 3000)
pnpm dev:server

# Run webapp + server concurrently
pnpm dev
```
