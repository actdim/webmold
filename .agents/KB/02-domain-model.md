# WebMold Domain Model

## Core Concepts & Showcases

- **Vite MPA Showcase**: Dedicated entry-point page (`index.html`) per UI component library.
- **UI Library Showcases**:
  - `shadcn`: Radix UI primitives with CSS variable themes.
  - `mui`: Material UI v7 component theme provider setup.
  - `prime`: PrimeReact v10 widgets and data table components.
  - `daisy`: DaisyUI v5 CSS class-based components.
  - `tw`: Pure Tailwind CSS + HyperUI component snippets.
- **Fastify API Server**: Backend API endpoints with TypeBox request/response schemas.
